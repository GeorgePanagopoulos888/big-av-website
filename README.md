# BIG AV Corporate Website

Static corporate site for BIG AV, a division of Salex Inc.

## What is included

- Corporate homepage
- Eight vertical market pages and a market index
- Scope of services, company, contact, privacy, and terms pages
- Agentic AI division page
- Preserved noindex Bradley orbit demo at `/agentic-ai/orbit.html`
- Shared responsive chrome and components in `styles.css`

## Run locally

Open `index.html` directly in a browser, or run:

```sh
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

Contact uses plain `tel:` and `mailto:` links. The site has no form backend and performs no account or calendar actions.
